Entry for [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) on make.fun.

This program writes the single word "unsubscribe" to `/output/entry.txt`. The modern internet runs on subscriptions, newsletters, notifications, and feeds you never quite asked for, and "unsubscribe" is the one link buried at the bottom of every email that everyone hunts for. It captures the noise, the commerce, and the universal desire for a quieter inbox in a single word.

Run it with:

```
python3 main.py
```
